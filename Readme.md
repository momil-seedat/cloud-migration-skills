# Cloud Migration Skills

This repository provides a collection of skills to assist with various aspects of cloud migration, developed by Momil. Each skill focuses on a specific migration scenario and includes detailed guidance, best practices, and examples.

## Available Skills

### Monolith to Microservices

The [Monolith to Microservices](monolith-to-microservices/SKILL.md) skill helps you migrate a monolithic application to a microservices architecture. It provides a step-by-step approach for decomposing a monolith into loosely coupled services, along with guidance on data management, API design, and incremental migration strategies.


### junit test
Use [Junit Test skill](junit-test-skill/SKILL.md) to generate unit test cases for your repository

## How to Use the Skills

1. Browse the available skills in the repository and navigate to the directory of the skill you want to use.
2. Read the `SKILL.md` file in the skill's directory for a detailed explanation of the migration scenario, key considerations, and the recommended process to follow.
3. Review the `examples/` directory for sample code, templates, and configuration files related to the skill.
4. Follow the step-by-step guide in the `SKILL.md` file to apply the skill to your specific migration project.
5. Adapt the guidance and examples to fit your project's requirements and constraints.
6. Refer to the "Common Pitfalls" and "References" sections in the `SKILL.md` file for additional tips and resources.
